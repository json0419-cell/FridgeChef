Generated assets for Play Console > Grow users > Store presence > Main store listing > Graphics.

## Upload mapping

- App icon: `app-icon-512.png`
  - 512x512 PNG with alpha channel
  - Under 1024 KB
- Feature graphic: `feature-graphic-1024x500.png`
  - 1024x500 24-bit PNG, no alpha
- Phone screenshots:
  - `phone-01-home-1080x1920.png`
  - `phone-02-recommendations-1080x1920.png`
  - `phone-03-add-ingredients-1080x1920.png`
  - `phone-04-libraries-1080x1920.png`
  - 1080x1920 PNG, no alpha
