# 保持纯客户端 BYOK，不建设开发者服务器

App 保持纯客户端架构，不建设开发者业务后端；Gemini 请求使用用户自己的 API Key 从设备直接发送给 Google。项目不接入自动崩溃上报、行为分析或其他 telemetry，避免服务器运维、开发者承担 token 成本和后台收集用户饮食数据。

## 后果

故障不会自动到达开发者，支持渠道是 Google Play 反馈和用户主动创建的 GitHub Issue。App 应生成可由用户检查、复制和主动提交的脱敏诊断信息，但不得包含 API Key、照片、已确认食材、饮食禁忌、个人菜谱内容或完整 Gemini 请求与响应。未来若引入开发者服务器或自动 telemetry，必须以新的 ADR 明确替代本决定并同步更新隐私政策。
