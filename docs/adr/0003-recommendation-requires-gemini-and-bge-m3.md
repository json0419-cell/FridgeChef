# 推荐功能要求 Gemini API Key 和 BGE-M3

推荐功能面向愿意自行配置 Gemini API Key 并下载约 2.29 GB BGE-M3 模型的用户。无论候选来自基础菜谱库、官方 `DatasetPack` 还是个人菜谱库，生成每一批新推荐都先使用 BGE-M3 做本地检索，再由 Gemini 结合食材、时间、人数和偏好整理结果；英文界面也由 Gemini 把纯中文候选整理为英文。该决定以更稳定的中英文语义检索和统一结果结构为优先，接受 BYOK、模型下载、联网和 token 消耗带来的首次使用门槛。

## 后果

推荐入口必须在运行前验证 API Key、AI 数据同意、模型安装和运行环境，并通过可恢复的设置流程引导用户。相同输入优先复用本地缓存；缓存身份必须包含食材、条件、语言及全部启用菜谱库的 ID 和版本。Gemini 失败时优先展示仍满足当前条件的最近缓存，没有可用缓存时可以展示明确标记的本地候选；BGE-M3 运行失败时回退基础菜谱库并说明高精度检索不可用。英文翻译结果按稳定菜谱 ID、数据集版本和语言长期缓存。

首次设置依次完成 AI 数据披露、Gemini API Key 实际请求测试、存储与网络检查、BGE-M3 下载与测试 embedding，以及菜谱来源启用。完整推荐批次只在输入签名完全一致时复用并保留七天；英文菜谱翻译保留到对应数据集版本变化，用户可以清除推荐缓存。打开页面或后台刷新不得自动调用 Gemini，只有用户明确执行“生成推荐”“换一批”或“应用新条件”才可产生请求。客户端仅对明确未到达服务端的连接错误自动重试一次，超时、配额、认证和响应格式错误由用户决定是否重试。公开首版固定使用经过测试的 `gemini-3.1-flash-lite`，变更 model ID 必须随 App 版本发布和验收。
