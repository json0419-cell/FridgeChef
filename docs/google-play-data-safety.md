# Google Play 数据安全表填写草案

更新日期：2026-09-02。提交 Play Console 前，应按届时实际发布版本、Google 的最新问题文案和第三方 SDK 再核对一次。

## 应披露的离机数据

当用户同意并主动调用 Gemini 时，下列数据会直接从 App 发送到 Google：

| Play 数据类别 | 本 App 中的内容 | 是否必需 | 目的 | 处理说明 |
| --- | --- | --- | --- | --- |
| 照片和视频 → 照片 | 用户选择或拍摄的食物照片 | 可选 | App 功能 | 加密传输；发送给 Google Gemini 服务商；不出售 |
| App 活动 → 其他用户生成内容 | 食材、菜谱文本、推荐候选、YouTube URL 与当次提示词 | 可选 | App 功能 | 加密传输；发送给 Google Gemini 服务商；不出售 |
| 健康与健身 → 健康信息 | 用户可能填写的过敏、忌口或饮食限制 | 可选 | App 功能/个性化 | 加密传输；仅在相关 Gemini 请求中发送；不出售 |
| 设备或其他标识符（需按 Google 最新分类复核） | 用户自己的 Gemini API Key | 可选 | 身份验证/App 功能 | 通过 `x-goog-api-key` 请求头直接发送给 Google；不写入 URL |

“可选”表示用户可以不使用 AI 功能，应用的本地菜谱库与手动功能仍可使用。完整本地菜谱库不会被自动上传。

## 本机数据与权限

- 食材、个人菜谱、历史、偏好、下载包和 AI 同意状态保存在本机，不因单纯本机处理而作为“已收集”上报。
- API Key 保存在 Android SecureStore；普通设置保存在应用私有存储。
- Release 最终 manifest 只保留业务/依赖实际需要的权限，不包含 `SYSTEM_ALERT_WINDOW`、麦克风、照片库或广泛存储权限。
- 相机权限只在用户选择拍照时请求。
- 应用未集成广告、分析或开发者自有账号/云同步 SDK。

## Play Console 建议答案

- 数据是否加密传输：是（所有应用配置的联网地址均要求 HTTPS）。
- 是否出售数据：否。
- 用户是否可以选择：是，首次 Gemini 调用前可拒绝，并可在设置中撤回。
- 是否有账号创建：否，因此不存在应用账号删除流程。
- 数据删除：本机数据可通过应用内删除、清除应用数据或卸载删除；清除 Key 会删除 SecureStore 中的 Key。Google 已接收数据的删除与保留由用户的 Google/Gemini 账号控制和 Google 政策决定。

## 发布前必须完成

1. 将仓库根目录 `PRIVACY.md` 的内容发布为公开 HTTPS 网页（不可要求登录、不可为 PDF、应允许普通浏览器访问）。
2. 在隐私政策网页中填写实际开发者名称及隐私联系邮箱或其他有效联系方式。
3. 将公开 URL 同时填入 Play Console 的“隐私政策”和商店详情，并确认应用内页面内容一致。
4. 重新检查最终 AAB 的 Data Safety/SDK Index 报告；新增 SDK、后台传输或账号功能后同步更新本表与政策。
